# Рефакторинг nagruzka.php

## Структура

```
ajax/get/nagruzka/
├── index.php                    # Точка входа, роутинг по режимам
├── BaseNagruzkaProvider.php     # Базовый класс с общей логикой
├── helpers/
│   └── SplitProcessor.php       # Обработка сплитов (распределений)
└── modes/
    ├── ClosedMode.php           # Режим "Закрыто"
    ├── FillingMode.php          # Режим "Заполнение" (текущий)
    ├── VerificationMode.php     # Режим "Выверка"
    ├── ArchiveMode.php          # Режим "Архив"
    └── ExportingMode.php        # Переходный режим выгрузки
```

## Использование

### Новая точка входа

Вместо старого `ajax/get/nagruzka.php` используйте:

```
/ajax/get/nagruzka/
```

Параметры те же:
- `type` — тип нагрузки
- `chair_id` — ID кафедры (для УОУП)
- `lecturer_uid` — UID преподавателя
- `lite` — лёгкий режим (для УОУП)
- `only_stat` — только статистика

### Режимы работы

Режим определяется автоматически из таблицы `params` (param='system_mode'):

| Режим | Значение | Описание |
|-------|----------|----------|
| Закрыто | `mode_closed` | Подготовка данных, завкафы не видят |
| Заполнение | `mode_filling` | Редактирование завкафами |
| Выгрузка в ГУВ | `mode_exporting` | Переходный режим |
| Выверка | `mode_verification` | Проверка, УОУП может править |
| Архив | `mode_archive` | Исторические данные |

### Права доступа по режимам

| Роль | Закрыто | Заполнение | Выверка | Архив |
|------|---------|------------|---------|-------|
| Завкаф | ✗ | ✓ просмотр+редактирование | ✓ просмотр, запросы в УОУП | ✓ просмотр |
| УОУП | ✓ просмотр | ✓ просмотр | ✓ просмотр+редактирование | ✓ просмотр |
| Сотрудник | ✗ | ✓ если есть lecturer_uid | ✓ если есть lecturer_uid | ✓ если есть lecturer_uid |

## Ключевые изменения

### 1. Читаемость
- Каждый режим — отдельный класс
- Методы `canView()` и `canEdit()` чётко определяют права
- Нет дублирующегося кода

### 2. Обработка сплитов
Вынесена в `SplitProcessor`:
- `applySplits()` — для режима Заполнения (перезапись данных Галактики)
- `applySplitsWithPriority()` — для режима Выверки (приоритет сплитам)

### 3. Расширяемость
Новый режим = новый класс:
1. Создать файл в `modes/`
2. Наследовать от `BaseNagruzkaProvider`
3. Реализовать `canView()`, `canEdit()`, `getData()`
4. Добавить в фабрику в `index.php`

## Выгрузка в Галактику

Скрипт: `once/export_to_galaxy.php`

Вызывается при переходе из "Заполнения" в "Выверку".

Этапы:
1. Выгрузка новой нагрузки (ИК/КСРО) из таблицы `ksro`
2. Выгрузка распределений (сплитов) из `zavkaf_splits`
3. Формирование XML для Галактики

## Тестирование

## Миграция

1. Старый файл `ajax/get/nagruzka.php` оставить как резерв
2. Переключить вызовы на новую точку входа `ajax/get/nagruzka/`
3. Убедиться что все режимы работают корректно
4. Удалить старый файл

## Отличия от старой реализации

| Было | Стало |
|------|-------|
| 546 строк в одном файле | ~350 строк распределены по классам |
| Смешанная логика режимов | Изолированная логика в каждом классе |
| Дублирование обработки сплитов | Единый SplitProcessor |
| Сложная отладка | Чёткая структура |
